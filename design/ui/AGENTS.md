# skydiiv-ui

## Language

All documentation, UI copy, comments, and source in this package MUST be written in **en-US**. Do not add Portuguese (or any other locale) to docs, tests, READMEs, or code comments.

## Source of truth

This package owns the design-system implementations: components, tokens, emoticons, and component styles. Storybook under `design/storybook` may document and demonstrate these modules. Do not add or edit component implementations in Storybook.
