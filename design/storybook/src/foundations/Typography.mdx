## Lowercase

All text is lowercase, except:

- Product name **<span className="brand-name">SkyDIIV</span>**
- Wordmark **<span className="brand-name">SkyCHNNLS</span>**
- Emails and other names where capitalization is part of the data

Wordmarks are identity, not running text.
