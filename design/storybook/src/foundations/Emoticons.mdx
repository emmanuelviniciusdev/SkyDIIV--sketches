# Emoticons

The set is historical KDDI pixel marks from the [Unicode full emoji list](https://unicode.org/emoji/charts/full-emoji-list.html). Keep them sharp. Do not replace them with system emoji.

The yellow sparkling star belongs in the set, but it is not an emoji. It is a mark with a soft glow and a slow twinkle.
