# Button

Default is a quiet bordered control. Primary is the filled emphasis, using the accessible fill with on-primary text. Outline keeps a stone border on the page color. Ghost stays text-only with no hover fill. Weight stays regular, never bold. Size is 13px with wide tracking.

Every action button includes a Phosphor icon at light weight. The icon sits on the left by default. Use the right for forward actions. Icon-only controls always provide an accessible name.
