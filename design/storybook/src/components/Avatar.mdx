# Avatar

A square profile mark with a compact corner. With a photo, the image fills the frame. Without a photo, the first letter of the name is shown. An algorithm assigns a fill from the logo letter colors, so each letter keeps a stable color. The letter stays a capital.

## Initial

## Letter color

The fill is not arbitrary. The initial is mapped to the SkyDIIV letter palette. A letter that appears in the wordmark uses that letter's color. Other letters still draw from the same palette. The same letter always receives the same fill.
